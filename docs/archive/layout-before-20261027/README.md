# 2026-10-27 문서 구조 변경 기록

`docs/` 최상위 문서 22개를 연구 근거, 최소 파일럿, 합성 삽입 실험, 공개 벡터 실험, 과거 제안으로 분류했다.
문서 간 링크와 코드 6개의 문서 경로를 갱신했다. 실험 조건·관측값·결론은 변경하지 않았다.

- [원본 압축본](snapshot.tar.gz): 이동 전 문서 22개, 저장소 README, 경로를 참조하는 Python 파일 6개. 총 29개 파일이며 경로는 저장소 루트 기준이다.
- [이동표와 원본 SHA-256](manifest.json): 이전·이후 경로, 원본 파일 해시, 기존 아카이브 8개 및 과거 제출 receipt의 해시.
- [현재 문서 목차](../../README.md)

완료된 실험의 원시 결과, 제출 receipt, 동결 source snapshot은 변경하지 않았다. 과거 receipt의 문서·코드 해시는 압축본의 원본과 대조한다. 현재 문서로 과거 제출 검증을 재실행하거나 완료 시각·기한을 갱신하지 않는다.

원본을 열 때는 압축본을 별도 임시 디렉터리에 해제한다. 현재 저장소에 바로 풀면 정리한 파일을 덮어쓸 수 있다. 원본 문서의 상대 링크는 이동 전 배치를 기준으로 한다.

## 이동 후 확인 결과

2026-10-27 로컬에서 확인했다.

- 이동표 22개 전부 새 경로에 존재하고 이전 경로에는 남지 않았다.
- Markdown 본문 21개를 압축본과 비교해 링크·경로 치환 외 변경이 없음을 확인했다. 시나리오 JSON은 SHA-256이 같다.
- 압축본 29개 파일, 기존 아카이브 8개, 확인 대상 제출 receipt 2개의 SHA-256이 이동 전 기록과 같다.
- 현재 Markdown 및 새 아카이브 안내 문서 25개의 상대 파일 링크에 누락이 없다. 기존 아카이브 내부 링크는 원본 보존 대상으로 검사에서 제외했다. 존재하지 않는 링크를 넣은 검사 입력은 실패했다.
- 변경한 Python 파일 6개는 AST 구문 검사를 통과했다.
- `study.prepare.source_receipt`를 임시 디렉터리에 실행해 새 계획·참고문헌 경로의 복사 및 해시 일치를 확인했다.
- `scripts.summarize.summarize`와 `analysis.final_report.run`을 기존 완료 결과에 대해 임시 출력 경로로 실행했다. 생성된 로컬 링크는 각각 1개, 13개 모두 유효했다. 후자의 감사·제출 receipt 저장 호출 2개는 가로채어 원본에 기록하지 않았다.
- 첫 임시 검사 실행은 모듈 탐색 경로 누락으로 실패해 `PYTHONPATH`를 지정했다. 이어 파일럿 보고서의 임시 경로 검사에서 macOS 심볼릭 링크 경로 차이를 발견하고 출력·근거 경로를 정규화한 뒤 두 생성기 검사를 통과했다.

DB 실험과 과거 12시간 제출 검증 전체는 재실행하지 않았다. 위 검사는 문서 이동 및 경로를 사용하는 코드의 검증이며 새로운 측정 증거가 아니다.
