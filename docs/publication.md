# 공개 저장소의 범위

이 저장소는 실험 코드, 계획·실행·결과 문서, 클러스터별 삽입 실험의 최종 집계 결과를 공개한다.

- 기술보고서: [클러스터별 증분 삽입](real-vectors/clustered/technical-report.md)
- 실험: `runs/clustered-20261027-02`
- 최종 집계: 해당 실험의 `cells/report__all/948e89fb-cd1c-4c27-a692-cdb7b751396e/`
- 공개 집계에는 endpoint, contrast, ef 곡선, 시점별 궤적, 질의 집단, 비용·자원 요약 및 완료 판정이 포함된다.

원본 임베딩, DB 스냅샷, 전체 개별 측정 receipt, Docker·프로세스 로그 및 과거 실행 디렉터리는 이 Git 저장소에 포함하지 않는다. 원본 공개 데이터의 다운로드 위치와 준비 코드는 보고서와 구현에 있다. 따라서 문서의 로컬 경로 및 전체 증거 링크 중 일부는 공개 저장소에서 열리지 않는다. 최종 집계 공개는 전체 원시 실행 증거의 공개나 외부 독립 재현을 뜻하지 않는다.

기존 결과 문서는 해시 보존을 위해 수정하지 않았다. 코드나 집계를 게시하는 과정에서 DB 실험을 다시 실행하지 않았다.
